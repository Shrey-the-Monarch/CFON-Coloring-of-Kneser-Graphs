\section{Efficient open dominating sets and CFON$^{*}$ 1-colorings}

% CHANGED: the first sentence of the notes also stated the claim for the odd
% graph K(2k+1,k); only the definition is kept here, since this file is about
% K(2k+n,k). "efficient dominating set" is written "efficient open dominating
% set" throughout. "which a subset" -> "is a subset".
An efficient open dominating set of a Kneser graph $K$ is a subset of the
vertices, call it $T$, of the $K$ graph where every vertex in $K$ has
\underline{exactly} 1 neighbor in $T$.

Note that an efficient open dominating set is analogous to a CFON$^{*}$
1-coloring because if $T$ is the set of all colored vertices (since we only
have one color, we can treat all colored vertices as the same).

Let each vertex, $v$, in $K$ be assigned a variable:
\[
  x_v =
  \begin{cases}
    1, & v \in T\\
    0, & v \notin T
  \end{cases}
\]

Thus, summing all the vertices in the open neighborhood $N(v)$ will equal 1.

\section{The matrix equation}

So for every vertex $u$ in $N(v)$:
% CHANGED: ||N(v)|| -> |N(v)| (cardinality).
\[
  \sum_{u \in N(v)} x_u
  \;=\; \underbrace{0 + 0 + 0 + \cdots}_{|N(v)|-1}
  \;+\; \underbrace{1}_{\text{the colored vertex}}
  \;=\; 1
\]

Let $A$ be a matrix with each row and column representing a vertex. If an
element is in a row-column pair whose respective vertices are adjacent let it
be equal 1, otherwise let it be zero.

\section{The general case $K(2k+n,\,k)$}

We generalize: $K(2k+n,\,k)$; $k \ge 1$, $n > 0$.

The graph is $\dbinom{k+n}{k}$-regular.

% CHANGED: "corresponding matrices are adjacent" -> "corresponding vertices".
The adjacency matrix with each row and column corresponding to a vertex, with
an element equalling 1 if the row and column's corresponding vertices are
adjacent and 0 otherwise has $\dbinom{k+n}{k}$ 1's in each row. Let this
matrix be $M$.

\[
  Mq = \mathbf{1}, \qquad \text{suppose } q =
  \begin{bmatrix} g \\ g \\ \vdots \\ g \end{bmatrix}
\]

% CHANGED: the notes have ((k+n)!/k!) g = 1 and g = k!/(k+n)!. The degree is
% the binomial coefficient (k+n)!/(k! n!), so the n! is restored.
Then,
\[
  \left( \frac{(k+n)!}{k!\,n!} \right) g = 1,
  \qquad
  g = \frac{k!\,n!}{(k+n)!}
\]

The eigenvalue
\[
  \lambda_j = (-1)^j \binom{k+n-j}{k-j}, \qquad j = 0, 1, 2, \dots, k
\]

% CHANGED: the notes say the magnitude is never 0 "because n is strictly
% greater than 0". The eigenvalues are nonzero for every n >= 0; what n > 0
% gives is degree >= 2, i.e. fractional entries of q. The reason is corrected
% here and the n > 0 clause is moved below, to where it is used.
So its magnitude is never 0 because $k+n-j \ge k-j \ge 0$ for every $j$, which
makes every $\dbinom{k+n-j}{k-j}$ at least 1. Thus the eigenvalue for $M$ is
always non-zero, making $M$ invertible.

% CHANGED: the notes say "Using the same invertibility argument as before, q
% is the unique solution, and all it's elements are fractional, so no
% efficient open dominating set exists." The argument referred to is written
% out below for M and q, in the wording the notes use for K(2k+1,k), so that
% this file stands on its own. N_0^n is written N_0^{|V(K)|} so the exponent
% does not collide with the n of K(2k+n,k).
Now suppose there was some vector $w$ such that $Mw = \mathbf{1}$, and
$w \in \mathbb{N}_0^{|V(K)|}$ such that it meets CFON$^{*}$ coloring
restrictions.

Then:
\begin{align*}
  Mw &= Mq = \mathbf{1} \\
  M^{-1}Mw &= M^{-1}Mq && \text{(we've proven invertibility)} \\
  w &= q,
\end{align*}
but $q$ is fractional, because $n$ is strictly greater than 0, which makes
$\dbinom{k+n}{k} \ge k+1 \ge 2$ and so $g < 1$. This contradicts the definition
of $w$. Thus, $w$ cannot exist, and $q$ is the unique solution.

Since $q$ is the unique solution and all its elements are fractional, and
since $x_v$ can only equal 0 or 1 based on its inclusion in $T$, no efficient
open dominating set exists and thus $K(2k+n,\,k)$ is not 1-colorable.
